Using This Application

Register students, find records with search and filters, and view, edit or remove student information from the Students directory. Your records are saved in this browser and remain available after refresh.

This is a front-end demonstration. Data is stored locally in the current browser and is not synced to a server.

About Project

Project Goal

This dashboard demonstrates a beginner-friendly student registration system for educational institutions. It highlights clean JavaScript logic, browser storage and a professional interface.

Key Features

  • Student registration and validation
  • Search, filters and dynamic dashboard statistics
  • Editable and deletable records with local persistence
  • Responsive, accessible and mobile-friendly layout
